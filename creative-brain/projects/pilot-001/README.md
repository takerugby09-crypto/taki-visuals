# PILOT-001 — 最初の制作実験

状態：**企画・生成前（2026-11-15）**。これはデモ企画であり、画像・動画はまだ生成していない。

## 目的
Codexで案を設計 → Higgsfieldで生成 → 作品を評価 → GitHubに改善点を記録する「制作サイクル」を1回通す。Instagramの反応は公開した場合にのみ追記する。

## 3つの異なる企画候補
| 案 | 一文 | 学ぶ技術 |
|---|---|---|
| A：光と水 | ガラスに落ちた水滴の内部に小さな光の世界が生まれる | マクロ構図、光、Image-to-Video、Dolly In |
| B：スケールの錯覚 | 巨大な本の上を小さな探検家が歩く | 視点・構図、サイズの連続性 |
| C：素材の変化 | 粘土の造形が少しずつ異素材に変化する | 質感表現、変形制御、編集 |

**今回の技術テスト推奨：A**。ジャンルの長期固定ではなく、人物の顔や衣装の一貫性を気にせず、画像→動画の動作とカメラの指示を練習するため。

## A案：15秒を目指すショット設計（3カット）
| ID | 目安 | 画 | 画面で起こること | カメラ |
|---|---|---|---|---|
| S01 | 0〜5秒 | Wide / Medium | 暗い空間でガラス表面に水滴が現れる | 静止→ゆっくり寄り |
| S02 | 5〜10秒 | Extreme Close-up | 水滴内で光が屈折し、虹色に変化する | ゆっくりDolly In |
| S03 | 10〜15秒 | Macro Detail | 水滴が転がり、光の筋だけを残す | ゆっくりTracking |

合計15秒は**編集後の目標**。動画モデルの実際の生成可能秒数に合わせ、短いクリップを結合・トリミングする。

## 初回素材
- **縦型9:16** のキー画像をまず1枚生成。
- 光と水滴の位置・色・背景を採用画像で固定する。
- S01のみ短いImage-to-Videoで試し、問題点を記録してからS02/S03に進む。
- 利用権を確認した音源を使用。初回は音声生成不要。

## 実行順
1. `prompts.md` の画像用プロンプトを実行可能なモデル仕様に合わせて確認。
2. 1枚生成、採用 / 修正を決める。
3. その画像を開始画像にしてS01を動画化。
4. 生成結果を `review.md` に記録。
5. 問題が解決したら残り2カットへ拡張。
6. 音楽に合わせた編集・投稿の結果を追加。
