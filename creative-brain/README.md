# TAKI CREATIVE BRAIN — v0.3

AI映像制作のための、ジャンルを固定しない「制作知識と実験記録」の土台。

## 目的
1. 思いつきを作品にする。
2. Higgsfieldの使い方を**実際の制作**で覚える。
3. 成功だけでなく失敗・修正も記録する。
4. Instagramでの反応を検証し、次の制作に活かす。
5. 映像制作とWeb制作のポートフォリオを育てる。

## 基本原則
- **世界観を固定しない**：実写、アニメ、広告、抽象、ドキュメンタリー等を自由に横断する。
- **好みと成果を混同しない**：自分が好きな作品とSNSで伸びた作品を別々に評価する。
- **生成を完成と呼ばない**：選定・構成・音楽・編集までが映像作品。
- **AIが提案するだけで決定しない**：最終的な表現の判断は制作者が行う。
- **モデル仕様・UIは変化する**：手順や機能名は検証日とともに記録する。
- **公開可否の確認**：素材、人物、楽曲、ブランド、依頼者情報の利用権を確認する。

## 使い方
1. `ideas/idea-template.md`をコピーしてアイデアを記録。
2. `guides/higgsfield-workflow.md`を参考に制作。
3. `projects/project-template.md`をコピーしてプロジェクト開始。
4. 生成結果・修正・学びをその都度書く。
5. 投稿後に分析し、次作で試す仮説を1つ決める。

## 将来の拡張
Codexで検索機能、タグ付け、制作ダッシュボード、プロンプト比較、ポートフォリオ連携を追加していく。現時点では**自動でHiggsfieldやInstagramの結果を取得する機能はない**。

## 現在の構成
- `creative-principles.md`：企画・批評時の判断軸
- `guides/higgsfield-workflow.md`：これまでのレッスンの学習要点（要実機検証）
- `ideas/idea-template.md`：思いつきの記録
- `projects/project-template.md`：制作工程と改善
- `analytics/post-template.md`：投稿後の検証
- `lessons/`：Academy画面録画5本の要点・実践ワーク
- `sources/`：その他の解説動画、英語文字起こし、参考作品の確認状況と学習ノート
- `integrations/higgsfield-codex.md`：Codex→Higgsfieldの制作指示の受け渡し（直接自動実行は未実装）

既存のポートフォリオ（ルートのHTML/CSS/JS）は変更しない。

## 参考動画の扱い
`sources/README.md` を開き、A（文字起こし全文）/B（過去の要点）/C（リンクのみ）/D（画面録画の要点）の確認レベルを区別する。既存ノートはAIの学習用索引であり、元動画や全文書き起こしがGitHubに保存されているわけではない。
