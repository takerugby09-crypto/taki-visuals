## 運用
1. 出典URL、ユーザー提供資料名、確認範囲を必ず区別する。
2. ツール名・モデル仕様・料金は公開時期で変わるため使用前に確認する。
3. 作品で試したら「入力・設定・生成結果・問題・改善」を記録。
4. 権利未確認の動画・文字起こし全文や個人情報は公開リポジトリに入れない。
5. **参照可能**と**自動で覚えて常時参照**は別。Codexが使う際にはこのディレクトリを明示して読む。
