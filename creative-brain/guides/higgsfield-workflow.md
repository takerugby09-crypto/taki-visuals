# Higgsfield Academy 学習メモ（5本分の統合版）

> これまでの会話で整理した画面録画の要点を、今後の実験で使うために再構成したもの。**英語の逐語訳・公式仕様保証ではない。** UI名称・モデル仕様・画面は実際の利用時に確認する。

## レッスン1：最初の動画
- 目的を一文にする。
- モデルが多くても「このシーンの目的」で選ぶ。
- まず短い動画を生成し、成功・失敗を記録する。
### 実践
15秒前後の短い映像を1本。選んだモデルと理由、結果を書き残す。

## レッスン2：AIに制作意図を伝える
- 自分の立場、必要な成果物、作業内容、出力形式を明確にする。
- 背景情報や参考資料を渡す。
- 一度で完璧を目指さず、同じ制作目的の中で改善する。
### 実践
「1つの制作指示＋3つの参考資料」を準備。初回と改善後の指示を比較する。

## レッスン3：素材づくり
- 人物・商品・背景など、動画の元になる静止画像を作る。
- 構図・照明・服装・画風を意識する。
- 動画化前に元画像を選び、必要なら修正する。
### 実践
1つの被写体で、同じ世界観の画像を3枚生成。何が変わったかを確認する。

## レッスン4：一貫性と参考素材
- 場所、人物、小道具を分けて準備する。
- 複数アングルや表情を揃える。
- カット間で外見・配置が変わらないか確認する。
### 実践
同じキャラクターまたは物体を3アングルで作り、変わってしまった部分をメモする。

## レッスン5：ショット設計とプロンプト
- 誰が・どこで・何をするかを指定する。
- Full / Medium / Close-upなどを役割で選ぶ。
- カメラ位置、移動、前景・中景・背景の奥行きを考える。
- 音・尺・動作も必要に応じて指定する。
- 使えるテイクは残し、必要箇所を改善する。
### 実践
1つの出来事を「広い画」「人物の動き」「細部」の3カットに分け、各カットを生成する。

## 動画制作の共通ワークフロー
企画 → 参考資料 → キーフレーム画像 → 動画化 → 複数ショット → 音楽と編集 → 作品確認 → 投稿・分析。

## モデル別の考え方（別動画の学び）
- Nano Banana Pro：画像の初期生成や部分的な修正を試す。
- Kling：静止画像を動かすとき、主役の動作とカメラ移動を明示する。
- 21:9は映画的な横長構図の**選択肢**。Instagram Reelsなら9:16も検討。
- 「映像がきれい」だけでは完成しない。編集順序、音楽、テンポが重要。

## 生成結果チェック
- [ ] 顔・服装・小物は崩れていないか
- [ ] 指定した動作を行ったか
- [ ] カメラの動きは意図どおりか
- [ ] 不自然な変形・余計な物体はないか
- [ ] 次のカットとつながるか
- [ ] 音楽と合っているか
